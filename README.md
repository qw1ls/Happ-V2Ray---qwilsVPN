<details>
 <summary><b>В чем разница между черными и белыми списками в VPN?</b></summary>
  
Это функция раздельного туннелирования, которая позволяет направлять через VPN не весь трафик устройства, а только выбранные сайты и приложения.

<b>Черные списки (Режим обхода / Bypass)</b>
В этом режиме VPN включен постоянно для всего интернета, кроме тех ресурсов, которые вы внесли в список.
* Как работает: Вы добавляете в список приложения банков и государственные сервисы. Они будут открываться напрямую через ваш обычный интернет, а весь остальной трафик по умолчанию пойдет в зашифрованном виде через VPN.
* Кому подойдет: Тем, кому важна постоянная приватность на любых новых сайтах.

<b>Белые списки (Режим "Только VPN" / Only VPN)</b>
В этом режиме VPN полностью выключен для всего интернета и активируется только тогда, когда вы заходите на сайты из списка.
* Как работает: Вы добавляете в список только заблокированные ресурсы. Когда вы смотрите видео или листаете локальные соцсети, трафик идет напрямую через вашего провайдера на максимальной скорости. Но как только вы открываете сайт из списка, автоматически подключается VPN.
* Кому подойдет: Идеально для повседневного использования, так как экономит заряд телефона и не перегружает VPN-сервер лишним трафиком.

</details>
